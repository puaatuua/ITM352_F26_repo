# Sales Data Dashboard

## Description
This Python program loads sales data from a CSV file and provides an interactive
menu for analyzing the data with pandas pivot tables.

## Features
- Displays the first selected rows of the dataset
- Calculates total sales by region and order type
- Calculates average sales by region, state, and order type
- Analyzes sales by customer type and order type
- Calculates sales by region and product
- Calculates maximum and minimum prices by category
- Counts unique employees by region
- Creates custom pivot tables
- Compares two analytics side by side
- Allows the user to select specific rows or row ranges for each analysis

## Requirements
- Python 3
- pandas
- pyarrow
